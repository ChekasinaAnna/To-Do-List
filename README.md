# Список задач

Одностраничный список задач на HTML, CSS и JavaScript. Можно добавить задачу кнопкой или клавишей Enter, отметить её выполненной, вернуть в работу и удалить. Отмеченные задачи переходят в раздел «Выполнено» под активными. Последнее удаление можно отменить. Список и отметки хранятся в браузере и восстанавливаются после обновления страницы.

## Запуск

Из папки проекта запусти локальный сервер.

~~~sh
python -m http.server 8000 --bind 127.0.0.1
~~~

- [Пустой список](http://127.0.0.1:8000/)
- [Демо с тремя задачами](http://127.0.0.1:8000/?demo)

Демо хранит изменения отдельно от обычного списка.

## Проверка

1. Открой пустой список и попробуй отправить поле, заполненное пробелами. Под полем появится сообщение.
2. Добавь три задачи, в том числе одну с длинным названием. Отметь одну и проверь, что она перешла в «Выполнено». Сними галочку и убедись, что задача вернулась в «В работе». Отметь её снова и удали одну из активных.
3. Верни удалённую задачу кнопкой «Отменить». Проверь её положение и статус, затем удали её снова.
4. Обнови страницу. Две оставшиеся задачи и их статусы сохранятся.
5. Отметь все задачи и проверь состояние «Всё выполнено». На узком экране проверь переносы текста и работу с клавиатурой.
